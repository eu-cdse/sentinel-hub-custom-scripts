#  WDS Europe 60m Daily V2

The **Wet / Dry Snow (WDS)** product provides information on the snow state (wet or dry) by combining **Sentinel-1** radar-based wet snow maps within the snow cover extent derived from **Sentinel-2** optical data. Cloud detection in the Sentinel-2 imagery is performed using the [MAJA software](https://gitlab.orfeo-toolbox.org/maja/maja/).<br><br>It is generated in near real-time at European scale, with a spatial resolution of **60 m x 60 m** in areas where Sentinel-1 and Sentinel-2 observation tracks overlap.<br><br>**Data availability**: from 2016 to the present. No product is generated for a Sentinel-2 tile when cloud cover exceeds 90%.<br><br>More information [here](https://land.copernicus.eu/en/products/snow/high-resolution-wet-dry-snow).
