#  FCOVER 2014-2026 (raster 300 m), global, 10-daily – version 1

Corresponds to the fraction of ground covered by green vegetation. It quantifies the spatial extent of the vegetation. Every 10-days estimates are available in near real time at global scale in the spatial resolution of about 300 m from January 2014 to June 2020 based upon PROBA-V data with version 1.0 and from July 2020 to February 2026 based upon Sentinel-3/OLCI data with version 1.1.
